# AFRI-Plates: Cameroonian Food Recipe App
## Complete Requirements & Architecture Specification

### 🏗️ PROJECT OVERVIEW
- **App Name**: AFRI-Plates
- **Architecture**: Microservices with API Gateway
- **Frontend**: React Native (Expo Router + TypeScript) for Users, React Web for Chefs/Admins
- **Backend**: Node.js + Express + TypeScript + MongoDB
- **Authentication**: Clerk with RBAC + 2FA
- **Deployment**: Containerized services on Hostinger VPS
- **Team**: 4 developers

---

## 🎯 CORE MICROSERVICES ARCHITECTURE

### 1. **API-GATEWAY SERVICE** (Port: 8000)
**Purpose**: Central entry point, routing, authentication middleware, rate limiting

**Technologies**:
- Express.js + TypeScript
- Helmet, CORS, Rate limiting
- Clerk JWT validation middleware
- Request logging & monitoring

**Responsibilities**:
- Route requests to appropriate microservices
- Authenticate all requests using Clerk JWT
- Implement RBAC (Role-Based Access Control)
- Load balancing between service instances
- API versioning (/api/v1/)
- Request/Response transformation
- Centralized error handling
